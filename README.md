# 🌍 Earthius

> **Building the Future of Local AI**
>
> Earthius is a next-generation local AI platform powered by Large Language Models (LLMs). It is designed to evolve from a simple chatbot into a complete AI ecosystem with memory, agents, voice, vision, automation, desktop, mobile, and eventually its own custom language model: **EarthiusLM**.

**Version:** V1 (Development)
